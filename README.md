# **Caliax Helper v1.0.1**
**Caliax**, the best helper for browser - Strictly legal and _**100%** Safe_ **(Unless u are dumb)**.
This tool has been tested on Chromebook and Windows

## **Control**
1. **Toggle ESC** -> Hide/Show UI_
2. **Hold Shift( 5 Second )** -> Turn in to sniping tools mode to capture a screenshot.
3. **CTRL+ENTER** -> Send question

**How to Screenshot?**
First, hold down the Shift key for 5 seconds. After 5 seconds, the system will enter Snipping Tool mode, allowing you to easily take a screenshot of your browser. You can release the Shift key whenever you want to exit Snipping Tool mode.

## **How to Install?**
_Note* : This tools has been tested on **Chrome** so its highly recomend to use it in Chrome._
1. Download **CALIAX-HELPER** and extract the file.
2. Open Chrome and then go to **chrome://extensions/**
3. Turn on **Developer Mode** in the top right corner.
4. Click **Load Unpacked** button in the top left corner.
5. Open the extracted file and select **CALIAX EXTENSION**
6. Done! you can now enjoy Caliax in **dharmaputri.sokrates.co.id**
